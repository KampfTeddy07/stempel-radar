# Stempel-Radar Japan

Web-App zum Sammeln von Bahnhofs- und Sehenswürdigkeiten-Stempeln in Kyoto, Kansai, am Fuji und in Tokio.
Live-GPS, OpenStreetMap-Karte, Regions-/Artenfilter, Sammel-Status pro Gerät, offline nutzbar (PWA).

Installation am Handy: Seite in Safari/Chrome öffnen → „Zum Home-Bildschirm" / „App installieren".
